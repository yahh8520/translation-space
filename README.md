# translation-space

一个运行在桌面上的中英翻译工具。把翻译放进一张可置顶的悬浮卡片，输入或粘贴文字，就能在中文和英文之间转换。

日常翻译使用内置公共服务，无需填写密钥；需要更多表达方式时，可以连接自己的 OpenAI 兼容 AI 服务。

## 功能介绍

| 功能 | 说明 |
| --- | --- |
| 中英互译 | 默认自动判断翻译方向，也支持在标准卡片中手动选择 |
| 自动翻译 | 默认停止输入约 700 毫秒后翻译，中文输入法组词期间暂停，可在设置中关闭 |
| 普通翻译 | 内置 MyMemory，支持添加微软翻译、Google Cloud Translation Basic v2 和 LibreTranslate 配置 |
| AI 翻译 | 自定义端点、API 密钥、模型和补充提示词，支持多个引擎配置 |
| 多种译法 | AI 标准模式按语境提供最多三种不同译法；详细模式额外补充术语、歧义或表达说明 |
| 复制结果 | 每种译文独立复制，详细解释可单独复制 |
| 标准卡片 | 提供翻译方向、AI 模式、结果及窗口操作 |
| 迷你卡片 | 约 300 × 150，仅保留输入、译文、复制和必要操作；使用自动识别及标准翻译模式 |
| 桌面偏好 | 支持置顶、背景透明度、字号、启动显示及卡片模式设置 |
| 本地配置 | 保存引擎及窗口偏好，不保存翻译历史 |

标准卡片与迷你卡片可以随时切换，切换时保留原文和译文。两种模式分别记住窗口位置与尺寸，展开后恢复标准窗口大小。

## 支持平台

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| macOS | Apple Silicon / arm64 | `.dmg` |
| Windows | x64 | `.exe`，NSIS 安装程序 |

当前版本为 **0.2.0**，使用 Electron 构建。安装包体积优化暂缓，当前版本不以 30–60 MB 为交付指标。

## 开始使用

1. 安装并打开应用，首次启动会进入配置页。
2. 保留默认的 MyMemory 公共翻译，即可联网使用；也可以添加自己的翻译服务。
3. 点击「保存并打开卡片」，在卡片中输入或粘贴文字。
4. 停止输入后等待自动翻译，或点击翻译按钮立即执行。
5. 点击译文旁的复制按钮，将所需译文复制到剪贴板。

可以在卡片顶部切换迷你模式、置顶或隐藏窗口。隐藏后，通过 macOS 菜单栏或 Windows 系统托盘重新打开；退出应用使用菜单中的退出入口。

### 自动翻译与快捷键

- `⌘ + Enter`（macOS）或 `Ctrl + Enter`（Windows）：立即翻译。
- 连续输入会重新计时，避免每次按键都发出请求。
- 修改原文、翻译方向或引擎后，旧请求会失效，迟到的响应不会覆盖当前结果。
- 取消后，相同文本不会自动重启；可以修改文本或手动再次翻译。
- 隐藏卡片时暂停自动请求，恢复显示后可继续处理未完成的输入。
- 服务调用失败时显示错误，不会无限自动重试，也不会自动切换到其他付费引擎。

## 翻译引擎配置

在「翻译引擎」页面添加、编辑、删除或选择默认引擎。配置修改后需要保存；卡片中也可以切换当前引擎。

### 普通翻译

普通引擎主要返回译文，不额外生成 AI 解释。

| 引擎 | 默认端点 | 配置要求 |
| --- | --- | --- |
| MyMemory | `https://api.mymemory.translated.net/get` | 默认无需密钥，支持填写可选密钥 |
| 微软翻译 | `https://api.cognitive.microsofttranslator.com` | 填写资源密钥，资源区域按服务要求填写 |
| Google Basic v2 | `https://translation.googleapis.com/language/translate/v2` | 填写 Cloud Translation Basic v2 的 API 密钥 |
| LibreTranslate | `https://libretranslate.com` | 使用所选实例的基础地址或完整 `/translate` 地址，密钥按实例要求填写 |

公共服务的额度、网络可达性和翻译质量由服务提供方决定。MyMemory 长文本会按每段最多 500 UTF-8 字节拆分，保留换行并串行请求；分段可能影响上下文连贯性。具体服务规则请查阅 [MyMemory 接口说明](https://mymemory.translated.net/doc/spec.php)和[使用限制](https://mymemory.translated.net/doc/usagelimits.php)。

### AI 翻译

AI 引擎使用 **OpenAI Chat Completions 兼容协议**，需要配置：

| 字段 | 说明 |
| --- | --- |
| 显示名称 | 用于引擎列表和卡片中的识别 |
| 服务端点 URL | API 基础地址，例如 `https://example.com/v1`，或完整 `/chat/completions` 地址 |
| API 密钥 | 所选服务提供的凭据 |
| 模型名称 | 服务实际支持的模型 ID |
| 补充提示词 | 可选，用于补充语气、专业领域或表达偏好 |

应用已内置翻译提示词。标准模式优先提供译文，详细模式将解释与译文分开显示；补充提示词用于调整风格，待翻译原文按数据处理。

所有引擎均提供连接测试。测试会发送一段固定示例文本，可能消耗服务额度；兼容协议的服务仍可能存在差异，需要实际测试所选模型。

服务端点必须使用 HTTPS。本机 `localhost`、`127.0.0.1` 和 `[::1]` 服务允许使用 HTTP；端点中不要携带查询参数、用户名或密码。

## 数据与隐私

- 原文和译文只保留在当前窗口内存中，不写入翻译历史。
- 配置文件只保存引擎配置、加密密钥和窗口偏好。
- 密钥通过 Electron `safeStorage` 使用操作系统保护能力加密；系统加密不可用时拒绝保存，不降级为明文。
- 界面不回显已保存的密钥。编辑时留空可保留原密钥；更换服务商或服务源站后，需要重新填写密钥。
- 文本会在自动或手动触发翻译时发送给当前所选服务。MyMemory 使用 GET 查询，原文会出现在请求 URL 中；第三方服务的数据处理规则由其自行决定。
- 应用不持续监听剪贴板、不读取屏幕，也不包含统计上报。

为兼容旧版配置和系统密钥，产品改名后保留原存储身份。配置文件通常位于：

```text
macOS：~/Library/Application Support/译间/config.json
Windows：%APPDATA%/译间/config.json
```

系统加密可能绑定用户或设备，请勿将配置文件视为可跨设备恢复的密钥备份。

## 本地开发

需要 Node.js 24、npm，以及相应平台的图形桌面环境。进入项目目录后执行：

```sh
npm ci
npm run dev
```

界面由 Vite 提供热更新。修改 Electron 主进程、预加载脚本或翻译核心后，需要重新运行开发命令。

### 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发环境和 Electron 窗口 |
| `npm run typecheck` | 执行 TypeScript 类型检查 |
| `npm test` | 执行翻译核心和配置存储测试，使用模拟服务 |
| `npm run build` | 类型检查并生成生产构建 |
| `npm start` | 运行已有生产构建，首次使用前先执行 `npm run build` |
| `npm run test:e2e` | 构建并启动真实 Electron，使用本机模拟服务验证桌面交互 |
| `npm run test:public` | 使用固定示例调用真实公共服务，会消耗公共额度 |
| `npm run dist:mac` | 构建 macOS arm64 安装包 |
| `npm run dist:win` | 构建 Windows x64 安装包 |

核心测试、模拟服务桌面测试和真实服务调用分别执行。模拟测试通过不代表所有第三方服务或两端安装流程已验收。

## 构建与分发

建议分别在 macOS、Windows 环境构建对应平台安装包：

```sh
# macOS Apple Silicon
npm run dist:mac

# Windows x64
npm run dist:win
```

产物输出到 `release/`：

```text
translation-space-<版本>-mac-arm64.dmg
translation-space-<版本>-win-x64.exe
```

仓库提供 [GitHub Actions 构建工作流](.github/workflows/build.yml)，分别使用 macOS 和 Windows runner 执行测试并构建安装包。工作流由 `main` 分支推送、`v*` 标签、拉取请求或手动操作触发，产物上传至 Actions Artifacts，不自动发布到公开 Release。

默认构建没有配置发布证书。正式分发需要配置相应签名，macOS 还需公证；未签名测试包可能被系统拦截。证书和密钥应通过环境变量或 CI Secrets 提供，不能提交到仓库。

## 项目结构

```text
translation-space/
├── renderer/          # React 配置页、标准卡片和迷你卡片
├── electron/          # 窗口、菜单栏/托盘、系统加密和受限 IPC
├── core/              # 翻译引擎适配、配置校验和原子持久化
├── shared/            # 共享类型与默认配置
├── tests/             # 翻译协议和配置边界测试
├── scripts/           # 开发、构建、图标生成及桌面自测
├── assets/            # 应用与托盘图标
├── build/             # 安装包图标和 macOS 权限配置
└── .github/workflows/ # 双平台构建工作流
```

主要技术栈：Electron、React、TypeScript、Vite、Zod、electron-builder 和 Playwright。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 公共服务无法翻译或达到限额 | 检查网络，稍后重试，或手动切换自定义引擎 |
| AI 连接失败 | 检查端点是否为 API 地址、密钥是否有效、模型 ID 是否受支持 |
| 短词或中英混合文本识别错误 | 展开标准卡片，手动选择翻译方向 |
| 取消后没有继续自动翻译 | 属于预期行为，修改原文或手动再次翻译即可 |
| 卡片关闭后找不到窗口 | 从菜单栏或系统托盘重新打开 |
| 配置文件损坏 | 应用会保留原文件并报错，先备份，再检查文件内容或恢复配置 |

当前单次输入上限为 10,000 个字符，翻译请求总等待上限为 45 秒。首版只处理卡片内输入或粘贴的中英文本，暂不提供划词翻译、截图 OCR、文档翻译或历史记录。
